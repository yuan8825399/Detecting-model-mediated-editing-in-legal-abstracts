# CLAW-Edit v3 reproducibility release

This repository contains the reproducibility materials for the CLAW-Edit v3
formal source-screened benchmark and its lexical baseline analyses.

The release contains metadata for 493 source groups, 493 original records, and
7,888 controlled edit records. The original source-group partitions are
retained: train 243, dev 81, calibration 83, and test 86. The operation labels
H/E1/E2/E3/E4 identify the requested experimental operation; they are not
authorship ground truth or percentages of text generated by a language model.

## Release scope

The public package includes:

- text-free corpus records with IDs, labels, splits, hashes, quality fields, and
  provenance fields;
- generation metadata with provider, model, prompt ID, timestamps, status, and
  input/output/prompt hashes, plus redacted raw-response metadata and batch-run
  summaries;
- source-group and temporal split files;
- analysis metrics, prediction files, audit summaries, protocols, scripts, and
  manuscript figures;
- `SHA256SUMS.txt`, generated after the package was assembled.

Abstract and title text, raw provider responses, and the content-review sample
texts are intentionally omitted. The local audit found no confirmed license for
public redistribution of those third-party source texts. See
`DATA_ACCESS.md` for the exact omissions and the local source paths needed to
rebuild a controlled-access release.

## Reproduction

The scripts in `scripts/` expect the local source corpus and raw evidence paths
described in the original audit protocol. The v3 analysis outputs are already
included under `evaluation/`; the scalar JSON and Markdown reports should be
read together with the audit caveats in `docs/audit_package/AUDIT_REPORT.md`.

The v3 results are a quality-screened sensitivity analysis. The test set was
selected after earlier outputs had been inspected, and the calibration target
FPR was not achieved on the independent test set. These results must not be
reported as a general authorship detector or as semantic-preservation proof.

## Integrity

Verify all published files with:

```text
sha256sum -c SHA256SUMS.txt
```

On Windows PowerShell, use `Get-FileHash` and compare the SHA-256 values in the
same manifest.
