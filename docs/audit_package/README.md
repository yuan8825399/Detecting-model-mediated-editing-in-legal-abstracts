# CLAW-Edit v3: formal source-screened benchmark

## Scope and decisions

The formal v3 benchmark contains 493 source groups, 493 original abstracts (H),
and 7,888 controlled LLM edits (E), for 8,381 records. Each source group has
one H record and four E1-E4 records from each of DeepSeek, Doubao, Kimi, and
Wenxin. The original source-group split is retained: train 243, dev 81,
calibration 83, test 86. No human editing condition is included.

The latest manually reviewed v1 CSV determines source-group inclusion. It
already removed eight groups present in v2, including the group with two
Wenxin refusal outputs. Seven additional groups with visibly incomplete
original abstract endings were excluded at the user's instruction:

- `china-law-2004-00043`
- `china-law-2004-00047`
- `china-law-2004-00094`
- `china-law-2004-00115`
- `china-law-2005-00093`
- `china-law-2005-00094`
- `china-law-2008-00017`

The 33 retained original abstracts lacking terminal punctuation are accepted
as reviewed; no punctuation was inserted. This is a source-screened formal
version, not a claim that all edits preserve legal meaning.

## Provenance

Record text, titles, hashes, and raw-response references come from audited v2,
not from edited CSV text cells. The builder rechecked all 7,888 raw E response
files against their SHA-256 hashes and extracted contents. Thus `abstract_raw`
remains the captured source response. Derived `abstract_clean` has no `<正>`;
the marker-free `evaluation/analysis_records.jsonl` omits `abstract_raw` to
avoid confusing evidence with analysis input. No v1 or v2 file was overwritten.

The CSV contained text changes beyond source-group deletions, including edits
to `abstract_raw` that were not reflected in `abstract_clean`. They were not
silently incorporated as model outputs. `manifest.json` records the exact CSV
and parent-v2 hashes; `evaluation/provenance_audit.json` records counts and
accepted punctuation-only source IDs. `excluded_sources.json` records both
earlier and new exclusions with reasons.

## Tests

The fixed character 2-4 gram TF-IDF and balanced logistic-regression baseline
was retrained on v3 train sources. The threshold was chosen on calibration H
for a target FPR of 5%; independent test metrics are:

| Input | Test H | Test E | Test FPR | Mean TPR across 16 provider-level cells |
| --- | ---: | ---: | ---: | ---: |
| Abstract | 86 | 1,376 | 16.3% | 66.6% |
| Original title + abstract | 86 | 1,376 | 14.0% | 64.8% |

The abstract-only test FPR source-bootstrap 95% interval is 9.3%-24.4%.
Neither test FPR met the calibration target. These are outcomes of one local
baseline, not a general detector ranking or authorship ground truth. The
paired analysis and cross-provider conditions are in `evaluation/`.

The level-wise analysis in `evaluation/level_detection_and_score_response.md`
reports H-versus-E1/E2/E3/E4 AUROC and recall at the calibration-selected
threshold, plus within-source score trends and violations. For abstract-only
input, the four AUROCs are 0.600, 0.918, 0.893, 0.938; corresponding recalls
are 21.2%, 81.7%, 75.9%, 87.5%. Of 344 source-provider sequences, 17.4% are
strictly increasing across E1-E4 and 82.6% are not. E2-to-E3 scores decrease
in 61.6% of sequences. The full report includes title-plus-abstract results,
provider breakdowns, source-bootstrap intervals, and a within-sequence
permutation test. Recall should not be described as measured at 5% test FPR:
the 5% target was set on calibration H, while test FPR was higher.

The v3 exclusions were decided after v2 outputs and test results had been
inspected. Its test set is therefore a quality-screened sensitivity analysis,
not an untouched confirmatory holdout. Use a future independent source set for
confirmatory performance claims.

The content-review index has 7,888 E rows and no detected refusal output.
Its 347-row sample is a review queue; all semantic verdicts remain unfilled.
Risk flags, including the punctuation heuristic that may flag some accepted
source endings, are screening cues only. A previously noted legal-source
substitution (`wenxin-china-law-2009-00042-E1`) remains for explicit semantic
review and must not be described as meaning-preserving without adjudication.

## Continuous LLM-intervention prediction

For the continuous-prediction experiment, each record has a design label
`z` in `[0, 1]`: H = 0.00, E1 = 0.25, E2 = 0.50, E3 = 0.75, and E4 = 1.00.
This is a pre-specified proxy for the requested LLM editing operation, not a
measurement of actual LLM authorship, semantic contribution, or percentage of
text generated by an LLM. In particular, E1--E4 are independent edits of the
same H source rather than sequential revisions; their `z` values therefore
encode the experimental design and need not be recoverable as a natural
one-dimensional progression in every text.

`run_claw_edit_continuous.py` fits a class-balanced Ridge regressor over
character 2--4-gram TF-IDF features. It fits on 243 source groups, selects
the Ridge alpha with MAE on 81 development groups, fits a monotonic isotonic
calibrator on 83 distinct calibration groups, and evaluates once on 86 held-out
source groups. No source group crosses partitions. The script exports labelled
analysis records, per-record test predictions, and JSON metrics; 95%
confidence intervals are 1,000 source-group bootstrap resamples.

| Input | Test MAE (95% CI) | Test RMSE (95% CI) | Pearson r (95% CI) | Spearman rho (95% CI) |
| --- | --- | --- | --- | --- |
| Abstract | 0.2067 (0.1972--0.2169) | 0.2580 (0.2454--0.2713) | 0.5863 (0.5396--0.6306) | 0.5572 (0.5139--0.5985) |
| Original title + abstract | 0.2070 (0.1980--0.2166) | 0.2582 (0.2461--0.2714) | 0.5860 (0.5403--0.6287) | 0.5546 (0.5124--0.5939) |

These results are for one reproducible lexical baseline. The abstract-only
model systematically overpredicts H and underpredicts E4 in several provider
conditions, so its moderate association with operation levels is not evidence
that it reliably quantifies real-world AI involvement. As with the binary
results above, v3 was quality-screened after prior v2 outputs were visible and
must be presented as a sensitivity analysis rather than confirmatory evidence.

## Ordinal operation-level and robustness experiments

The same five operations were also evaluated as ordered labels (`H=0`,
`E1=1`, `E2=2`, `E3=3`, `E4=4`). The experiment uses cumulative ordinal
logistic regression with character 2--4-gram TF-IDF features. It separately
models `P(level > k)` for the four thresholds, calibrates each threshold on
the source-disjoint calibration partition, enforces monotonic cumulative
probabilities, and reconstructs a five-level probability vector. The label
still denotes the requested operation, not an observed amount of AI authorship.

| Input | Exact accuracy (95% CI) | Macro-F1 (95% CI) | Quadratic weighted kappa (95% CI) | Level MAE (95% CI) |
| --- | --- | --- | --- | --- |
| Abstract | 0.308 (0.285--0.331) | 0.261 (0.235--0.287) | 0.473 (0.429--0.522) | 1.199 (1.124--1.275) |
| Original title + abstract | 0.313 (0.289--0.336) | 0.267 (0.238--0.293) | 0.483 (0.429--0.535) | 1.179 (1.096--1.261) |

The 1,000-replicate confidence intervals above resample complete source groups.
Exact five-level recognition is limited, whereas the moderate weighted kappa
indicates that many errors are between adjacent requested-operation levels.
This distinction should be reported; it does not justify treating the output as
a reliable measurement of a writer's real LLM involvement.

`evaluation/ordinal_robustness.md` also reports three distribution-shift
conditions. In provider-held-out evaluation, test quadratic weighted kappa is
0.259 for DeepSeek, 0.509 for Doubao, 0.488 for Kimi, and 0.573 for Wenxin.
This provider variation is substantive evidence against assuming a
provider-invariant detector. For strict temporal extrapolation (train
2000--2010; development 2011--2013; calibration 2014--2016; test 2017--2020),
the abstract-only result is accuracy 0.288, Macro-F1 0.230, kappa 0.434, and
level MAE 1.253. Fixed-test performance also rises with H-abstract length:
short/medium/long strata have kappa 0.439/0.481/0.505 and level MAE
1.316/1.170/1.103. Length cut points are derived only from training H texts.

The benchmark has no human-validated legal-topic variable. Keyword or cluster
partitions therefore must not be described as cross-topic testing. A standard
Chinese pretrained-transformer baseline was not run because no such checkpoint
was cached locally and the attempted download of `hfl/chinese-roberta-wwm-ext`
timed out. The project-local Tiny-BERT checkpoints are not substituted for a
documented pretrained model. Once a versioned checkpoint is supplied, its
fine-tuning must preserve the same source-group partitions and keep the test
partition untouched.

## Reproduction

From the repository root, use a new output directory because the builder
refuses to overwrite an existing version:

```text
python build_claw_edit_v3.py --out research_benchmark_legal_edit_v3_rebuild
python run_claw_edit_baseline.py --root research_benchmark_legal_edit_v3_rebuild
python run_claw_edit_baseline.py --root research_benchmark_legal_edit_v3_rebuild --input-mode title_abstract
python analyze_claw_edit_scores.py --root research_benchmark_legal_edit_v3_rebuild
python review_claw_edit_content.py --root research_benchmark_legal_edit_v3_rebuild
python analyze_claw_edit_levels.py --root research_benchmark_legal_edit_v3_rebuild
python run_claw_edit_continuous.py --root research_benchmark_legal_edit_v3_rebuild
python run_claw_edit_continuous.py --root research_benchmark_legal_edit_v3_rebuild --input-mode title_abstract
python run_claw_edit_ordinal_robustness.py --root research_benchmark_legal_edit_v3_rebuild
```
